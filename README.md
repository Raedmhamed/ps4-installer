# PS5 Jailbreak Test (Simulation)

A web-based **simulation harness** for the PS5 browser: a fake "Jailbreak" button that runs a simulated jailbreak sequence with logs, plus notification testing. Nothing is actually exploited — runs entirely in the PS5 browser.

## Features

- Big **JAILBREAK (TEST)** button → simulated step-by-step sequence with progress bar
- Live log console (clear / export)
- **Notification test** (permission flow + send + custom title/body)
- Device / screen info
- Designed for touch: large buttons, no PC-only controls

## Usage

1. Host this repo (enable **GitHub Pages** on `main` / root).
2. Open the page in the PS5 browser (target 192.168.8.26).
3. Tap **JAILBREAK (TEST)**.

## Note

Simulation only. No real exploit is performed. Notification delivery on PS5 varies by firmware.
