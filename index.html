How it works
1. Open this page in your PS4 browser.
2. Browse the store, tap Download on a package.
3. The PS4 browser hands the .pkg to the system package installer.

Add your own packages
• Use the Add PKG tab, or edit packages.json in the repo.
• To share added packages with everyone, use Manage → Export packages.json and commit it.

Requirements
• PS4 firmware with a working browser & package installer.
• Direct links to .pkg files (no HTML wrapper pages).
• Enough free storage on the PS4.

Troubleshooting
• Nothing happens → enable pop-ups/downloads in PS4 browser settings.
• Host blocks hotlinking → try a different mirror.
• Large PKGs → keep PS4 awake; downloads may pause in rest mode.

Privacy
Everything runs locally in your browser. History and added packages live in localStorage. Nothing is sent anywhere except the PKG host you choose.
