How it works
1. Host this page (GitHub Pages works).
2. Open the page in your PS4 browser.
3. Paste a direct .pkg URL and tap Download PKG.
4. The PS4 browser hands the file to the system package installer.

Requirements
• PS4 firmware with a working browser & package installer.
• A direct link to the .pkg (no HTML wrapper / redirect-only pages).
• Enough free storage on the PS4.

Troubleshooting
• If nothing happens, enable pop-ups/downloads in the PS4 browser settings.
• Some hosts block hotlinking — try a different mirror.
• Large PKGs: keep the PS4 awake; downloads may pause in rest mode.
• Use the Batch tab to queue several PKGs; they download one at a time with a short delay to avoid browser blocking.

Privacy
Everything runs locally in your browser. URLs and history are stored only in this browser's localStorage. Nothing is sent to any server except the PKG host you choose.
