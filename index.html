How it works (no more "no memory" error)
Instead of downloading the PKG in the browser (which overflows PS4 memory), this page sends the PKG URL to your PS4's Remote Package Installer (RPI) on port 12800. The PS4 downloads & installs it itself.

Setup on PS4
1. Start GoldHEN (1.8+ / latest).
2. Install & launch Remote Package Installer homebrew (port 12800) — keep it in the foreground.
(GoldHEN → Debug Settings → Package Installer also works for manual URL entry.)
3. Make sure PS4 and this device are on the same network.

Usage
1. Enter your PS4 IP above and tap Test PS4.
2. Browse the store, tap Install on a package.
3. Watch progress on the PS4 (RPI screen).

Troubleshooting
• "Failed to fetch" → RPI not running / wrong IP / firewall. Keep RPI in foreground.
• Mixed-content blocked → open this page over HTTP or run a local server.
• Package rejected → host must serve the .pkg with proper headers; try a different mirror.
• Large PKGs → keep PS4 awake; downloads may pause in rest mode.

Privacy
Everything runs locally in your browser. History and added packages live in localStorage. Nothing is sent anywhere except your PS4 (12800) and the PKG host you choose.
